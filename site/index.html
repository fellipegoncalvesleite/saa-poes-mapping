Research overview

Method sensitivity of particle-defined South Atlantic Anomaly maps

Public NOAA POES/MetOp proton observations are mapped on coverage-aware geographic grids. The analysis changes one methodological choice at a time: flux threshold, proton channel, observation window, satellite, grid resolution, or summary statistic.

Scientific scope: Candidate high-flux footprints; not a definitive SAA boundary.

Results

Threshold sensitivity

Changing only the high-flux percentile moves and resizes the candidate footprint. The principal top-20% to top-1% comparison changes the stored flux-weighted centroid by about 386 km and selected area by about 17.7×.

Observation-window sensitivity

One day to the full month differs by about 288 km. Four separate weekly windows remain within about 118 km. The one-day result is orbit-track sparse and does not establish physical SAA motion.

Satellite sensitivity

The five-satellite principal top-10% spread is about 272 km. NOAA-18 and NOAA-19 differ by about 13 km. This comparison is limited to location and shape; absolute proton flux is not cross-calibrated.

Proton-channel sensitivity

Stored centroids for p1, p2, and p3 are separated by roughly 100–300 km. Absolute values at approximately 25, 50, and 100 MeV are different physical measurements.

Analysis pipeline

Method

Each experiment changes one declared method choice while holding the other supported choices fixed.

  1. NOAA satellite observations
  2. Assign observations to geographic cells
  3. Calculate statistic and sample count
  4. Apply coverage requirement
  5. Rank cells by flux
  6. Select the requested percentile
  7. Calculate area and flux-weighted centroid
Technical parameters

Region: latitude −70° to +20°, longitude −100° to +20°. Grids: 5° and 2°. January monthly coverage requires approximately 30 samples per cell; shorter windows scale that threshold with exposure. Tested statistics are mean and median; footprints use top 20/10/5/2/1 percentiles. Physical cell area uses spherical geometry. Rows with mep_IFC_on == 1 are removed; == -1 is retained and uninterpreted.

Descriptive IGRF comparison

Magnetic-field context

The particle-defined footprint is concentrated at relatively low regional modeled magnetic-field strength. The magnetic field describes the result; it does not define the footprint or establish causality.

Data and code

Reproducibility

The project uses NOAA/NCEI processed L1b POES/MetOp SEM-2 MEPED data from five spacecraft, a Python 3.12 pipeline, checkpoint validators, provenance records, checksums, and a deterministic frontend export.

Interpretation constraints

Limitations

  • January 2024 only.
  • Percentile-defined candidate footprint, not a universal boundary.
  • Primary analysis centered on p1 (~25 MeV).
  • No calibrated absolute cross-satellite flux comparison.
  • IGRF values are modeled quantities.
  • Sampling and local-time effects are not fully separated.
  • mep_IFC_on == -1 is retained and uninterpreted.
  • External scientific review is still required.
