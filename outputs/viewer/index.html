interactive method-sensitivity scientific viewer

EACH VALIDATED CONFIGURATION DISPLAYS A CANDIDATE HIGH-FLUX FOOTPRINT. The cells, masks, selected membership, centroid, area, and readout come from validated Python outputs. This browser code selects, colors, and displays stored values; it does no scientific recomputation.

Candidate threshold-defined footprint; not a final SAA boundary; not dose; not health risk; not a discovery claim. Cross-satellite absolute flux comparison is not allowed.

color = selected validated mean/median flux on a log10 viridis scale; thin grey lines = canonical cell geometry; geographic lines = Natural Earth context; black outlines = selected footprint; X = stored flux-weighted centroid.

blank = missing cell, coverage-failed cell, or a non-positive value that cannot appear on a log scale. Blank is never treated as zero or interpolated.

NOTES

  • Only the validated configurations within the chosen experiment are available.
  • Grid, statistic, channel, time, or satellite may change cell colors and footprint.
  • Threshold changes the precomputed selected-cell membership.
  • Coverage-failed cells are blank, not zero-filled.
  • Geographic context uses Natural Earth 1:110m coastlines and country boundaries (public domain) and does not affect the scientific grid or metrics.
  • Satellite comparison is location/shape only; no cross-satellite absolute flux comparison.
  • mep_IFC_on == -1 retained and uninterpreted.
